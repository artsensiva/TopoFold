# Public Abl HDX-MS data lead: inventory (2026-10-25)

**A data inventory, not an endpoint analysis and not a study.** It inspected the 3,386-byte DynamX export of PRIDE
PXD034008 and the article's two directly linked supplementary files. No raw mass-spectrometry file and no trajectory was
downloaded. Every number below is read from
[`hdx_inventory.json`](../benchmarks/audit/abl_hdx_lead_2026-10-25/results/hdx_inventory.json), generated by
`inventory_hdx_lead.py` (same directory).

## 1. The 3,386-byte file

- **Provider record (PRIDE, project PXD034008, licence CC0, submission type PARTIAL):** `REI_ABL_KB_dynamX_export_18May22.csv`,
  category SEARCH, 3,386 B, SHA-1 `6e3fe1eea1881ebbd96dad4d704e0ab426b938cb`. The downloaded file matches both
  (SHA-256 `2fd6b624a52fd5261c838f85a9c637f29b94e098297beb37f58c76b71705ca4a`).
- **Exact shape:** 82 lines, CRLF line endings, trailing newline. Line 1 is `,,,,,` (six empty cells), line 2 the header
  `Sequence,Start,End,MHP,MaxUptake,RT`, then **80 data rows** (first `ERTDITM,10,16,865.4084,6,4.493726`, last
  `VEKELGK,278,284,802.4669,6,2.585667`). 80 unique (sequence, start, end) rows.

**Stated only in the paper (not in this file):** the states (WT, A344V, M472I); exchange times 0.167, 1, 10, 60 and 240

## 2. The two directly linked files (structure only)

- **Source Data workbook** (`41467_2023_36956_MOESM6_ESM.xlsx`, 4,488,501 B, SHA-256 `1b32799c…`): 8 sheets, none with HDX content: Figure4B-kinetics,
  Figure4B-dasatinib, Figure4B-imatinib, Figure4C-FoldX, Figure4F-Tm, Figure4G-cellular IC50, Figure5A-Tm, FigureS4D-biochemical
  IC50. It is not "comparably small" in the literal sense (about 1,300 times the CSV); it was opened because it is the
  paper's own processed-data file and far below the 100 MB approval threshold, and only its structure was read.
- **Supplementary Information PDF** (1,468,412 B, SHA-256 `fb602254…`): Supplementary Table 1 (the summary above) and the
  caption of Supplementary Fig. 4B, "Full list of peptides with corresponding relative deuterium uptake at different exposure
  time points". The PDF holds 10 raster images and **no peptide row in its text layer**: the per-peptide uptake exists only as
  a picture, not as a table.

## 3. Is it sufficient for an endpoint? No. What is missing

1. A table of **relative deuterium uptake per peptide, per state (WT and M472I), per exchange time, per replicate**. Not in the
   CSV, not in the Source Data workbook, and in the paper only as an image (Supplementary Fig. 4B).
2. **Replicate-level values** and their error, to give a peptide-level noise estimate (the paper states the repeatability, not
   the data).
3. The **processing** that turns the 43 raw files (12.37 GB, proprietary Waters format) into uptake: DynamX 3.0 with manual
   inspection, not available locally and not planned.
4. The file as given supports only **peptide-to-residue mapping**: it confirms the +228 offset by exact sequence match (an
   independent confirmation of the earlier project mapping, 76 of 80 peptides exact).
