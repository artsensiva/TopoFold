# Next application: feasibility assessment (2026-10-25, metadata only)

**Scope.** This is a bounded, metadata-only comparison of candidate datasets for the next application after ABL-MYR-1b.
- No method was scored.
- No evaluation protocol was drafted or frozen.
- No dataset was downloaded.

**Data read**, all public, unauthenticated and anonymous:
- API metadata from Zenodo, RCSB, UniProt and the AWS S3 listing.
- One 38 kB topology file (`backbone_4-164.pdb`, whose MD5 matches Zenodo's).
- Two XTC frame headers (92 B each, so 184 B per trajectory) from each of 4 KRAS trajectories, read with HTTP range
  requests.
- From 2 Moonshot HDF5 files: only the HDF5 metadata, the time axis and the topology. These came to 983,040 B per file
  out of about 45 MB, and no coordinates were read.

Nothing was sent to anyone.

**Records.** Every number below is read from records generated by code in
[`benchmarks/audit/next_app_feasibility/`](../benchmarks/audit/next_app_feasibility/README.md):
- `results/feasibility_metadata.json`;
- `results/moonshot_h5_probe.json`.

ABL-MYR-1b is closed (D66). It is kept separate from this assessment, from Ayaz WT/M472I and from HDX.

**Note on "oncology-relevant".** SARS-CoV-2 Mpro is an antiviral target, not an oncology target. It is assessed first
because the task gave it priority. The KRAS candidate is the oncology one.

Equal-information baselines are the same for every candidate:
- **Method inputs.** Every method receives the same residues, the same frames and protein coordinates only. Ligand
  coordinates and the endpoint go to no method.
- **Baselines.**
  - The Cα baselines d(i,i+2), d(i,i+3) and RMSF, as in ABL-MYR-1b.
  - φ/ψ, as a comparator reported separately.
  - A PENSA-style torsion-distribution comparison as the strongest reasonable ensemble baseline (roadmap §12.1). It is
    not yet implemented in this repository.

## Recommendation

**Recommended (conditional): M1, Mpro apo vs holo localization against crystallographic fragment contacts.** The
essentials could be checked from public metadata and the two probed files:
- access terms;
- trajectory format, frame interval and atoms;
- residue mapping;
- an endpoint that is independent of TopoFold, structural and experimental;
- equal-information baselines;
- a bounded decisive subset.

The question it can answer: given protein coordinates only, does TopoFold localize the residues in contact with a
crystallographic fragment (computed from the PDB entry by a distance rule fixed in advance) better than the
equal-information baselines? It does not test activity, binding affinity or conformational selection.

**Limits of the verification:**
- Only RUN9 clone 0 was probed, in each arm. Clone completeness for the other RUNs is a size heuristic.
- Ligand residence in the holo clones is unknown.
- Because the ligand is present in the holo runs, the endpoint is expected to be detectable by construction. The test is
  therefore about relative localization, not about discovering a site.

**Best alternative: K1, the KRAS G12D GDP vs GTP comparison.** It is cheaper (60 MB), uses the existing XTC route, is
oncology-relevant, and has a conformational endpoint. Its main risk is that a GDP-started GTP ensemble may not relax
within about 2 µs, which would give an inconclusive result for every method. Choose K1 instead of M1 if the owner
prefers a strictly oncology-relevant target or a download under about 100 MB.

M2–M4 are kept in the record. They are not recommended now, for the reasons in the table.
