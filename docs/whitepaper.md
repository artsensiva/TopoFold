# TopoFold whitepaper (superseded)

This whitepaper (v0.7.0, attributed to "Artem Sensiva") is **withdrawn**. It reported results on synthetic ensembles described as real MD, "authentic" free-energy barriers that are estimator artefacts, and rotamer detection from the Cβ position, which is physically impossible. The author's name is Artem Galukhin.

The original text is available in the git history (commit `bb87544` and earlier). For the current, corrected description see [`../README.md`](../README.md), [`MANUSCRIPT_DRAFT.md`](MANUSCRIPT_DRAFT.md) and [`KNOWN_ISSUES.md`](KNOWN_ISSUES.md).
