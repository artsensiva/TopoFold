## Abstract (draft)

Analyses of molecular dynamics (MD) ensembles often need to compare the conformation of one region of a biomolecule across very many frames, independently of global rotation, translation and of motions elsewhere in the chain. Internal descriptors such as virtual bond angles and torsions of the Cα trace satisfy these requirements by construction, but are scattered across tools and are rarely available as fast, indexable representations. We present TopoFold, a memory-safe Rust library with Python bindings that computes discrete curvature, torsion, local writhe and a Cβ orientation angle for protein (and phosphorus-trace RNA) backbones, provides an approximate VP-tree candidate cascade for full-frame conformational search and an exhaustive invariant-distance search for explicitly selected residue subcurves, and provides a window-wise screen for multimodal local geometry. We describe the definitions and conventions, verify invariance and numerical correctness against reference implementations, quantify search recall against brute force, and evaluate the descriptors against equal-information local baselines on controlled synthetic tests and on independently generated MD data. ## 1. Introduction

Differential geometry has been applied to protein backbones for decades: curvature and torsion of the main chain (Rackovsky & Scheraga, 1978; Louie & Somorjai, 1982), virtual Cα bond angles and torsions (Levitt, 1976; Oldfield & Hubbard, 1994), and discrete Frenet frames (Hu, Lundgren & Niemi, 2011). Gauss-integral descriptors, including writhe, were used to classify protein folds (Røgen & Fain, 2003) and, recently, as features for Markov state models of intrinsically disordered proteins (Sisk, Olsson & Robustelli, 2025). Internal, superposition-free features — interatomic distances and backbone dihedrals — are also the standard input for dihedral PCA (Altis et al., 2007) and for TICA/VAMP-based kinetic models (e.g. PyEMMA, deeptime).

TopoFold does not introduce new descriptors. Its intended contribution is practical: (i) a single, tested, high-throughput implementation of these local descriptors with explicit sign and normalisation conventions; (ii) indexing of residue windows across large ensembles; and (iii) a screening procedure for windows whose local geometry is multimodal across an ensemble. The scientific question we test is whether such local invariants help to *find* and *compare* regions of conformational change better than, or at lower cost than, simple equal-information local baselines.

## 2. Methods

### 2.1 Discrete curvature and torsion
For a Cα trace r₀…r_{N−1} with unit tangents Tᵢ = (r_{i+1} − rᵢ)/‖r_{i+1} − rᵢ‖, curvature is κᵢ = arccos(T_{i−1}·Tᵢ) ∈ [0, π], and torsion is the signed dihedral between consecutive binormals Bᵢ = T_{i−1}×Tᵢ/‖·‖, τᵢ = atan2((B_{i−1}×Bᵢ)·Tᵢ, B_{i−1}·Bᵢ) ∈ (−π, π]. κ is invariant under all rigid motions and reflections; τ is invariant under proper rigid motions (SE(3)) and changes sign under reflection. Typical values: α-helix τ ≈ +50°, β-strand τ ≈ −170° (close to the ±π branch cut, see §2.4).

### 2.2 Writhe
For a polygonal curve, Wr = (1/2π) Σ_{i<j, |i−j|>1} Ω_{ij}, where Ω_{ij} is the signed solid angle of the spherical quadrilateral formed by segment pair (i, j), computed with the van Oosterom–Strackee triangle formula (Klenin & Langowski, 2000). Local writhe is the same sum restricted to a window. Writhe is an SE(3)-invariant geometric quantity, not a topological invariant. *Implementation note: v0.8.3 audit reproduction yields a −0.500 ratio relative to numerical Gauss-integral and polygonal references. The normalization and sign convention remain subject to independent Phase-3 validation (KNOWN_ISSUES M1).*

### 2.3 Cβ orientation angle
θβ,ᵢ is the angle of the Cα→Cβ unit vector in the local frame (Bᵢ, Nᵢ). Because Cβ is fixed by the N–Cα–C geometry, θβ encodes backbone geometry and does not report side-chain rotamers. Side-chain descriptors (χ angles or centroid vectors) are planned as a separate feature set.

### 2.4 Window-wise multimodality screen
For each window of w residues and each descriptor, the window average is computed per frame and the multimodality of its distribution across frames is scored. *v0.8.3 uses Sarle's bimodality coefficient on arithmetic means; this is planned to be replaced by circular statistics for angles and by a calibrated test (Hartigans' dip test or Gaussian-mixture ΔBIC) with false-discovery-rate control across windows (KNOWN_ISSUES M2, M3).* The screen ranks windows for inspection; it does not by itself identify functional sites or pockets.

### 2.5 Window search and indexing
Full-frame queries (`query()`) use a vantage-point tree over local-writhe spectra to obtain a candidate set, which is re-ranked using the current (κ, τ) Fréchet distance against the query frame. This cascade is approximate; we report Recall@k against brute force (§6). Subcurve queries (`query_subcurve()`) perform an exhaustive search using an SE(3)-invariant Fréchet distance over explicitly selected residue ranges. [Distance definition for same-sequence frames: per-residue distance vs discrete Fréchet — to be decided, KNOWN_ISSUES M5.]

### 2.6 Correlation network
Per-residue feature vectors of the current centered descriptors (κ, τ, θβ) are compared with a covariance-based regularized Gaussian mutual-information estimate I = −½ log(det C_ij / (det C_i det C_j)) and transformed to r = √(1 − e^(−2I)). The current v0.8.3 implementation does not use (sin τ, cos τ) embedding, copula normalization or the /d dimensional adjustment. [Planned changes: circular-variable treatment, estimator choice, significance testing — KNOWN_ISSUES M7.]

### 2.7 Implementation
Rust workspace (core geometry, index, I/O, PyO3 bindings), `#![forbid(unsafe_code)]`, Rayon parallelism; DCD and multi-model PDB readers. Complexity: O(N) per frame for κ, τ, θβ; O(w²) per window for local writhe.

## 4. Controlled synthetic experiments

Synthetic ensembles with injected local transitions and noisy termini test whether a method recovers a known signal. All local methods receive the same target loop; global Cartesian PCA is retained only as a contextual global baseline. Future validation requires both equal-information local-vs-local comparisons and blind-localisation experiments. Preliminary result with an independent NumPy re-implementation on the project's synthetic bistable benchmark (60 residues, loop 25–35, 2000 frames, true labels known):

| Representation (same loop for local methods) | Silhouette |
| --- | --- |
| Global Cartesian PCA, Kabsch on all residues | 0.337 |
| Local Cartesian PCA, Kabsch on loop | 0.961 |
| Loop Cα–Cα distances + PCA | 0.990 |
| Loop (κ, τ) + PCA | 0.992 |

Thus, when the region is known, simple local features suffice; the relevant test for TopoFold is blind localisation, where the region is not given. ## 7. Limitations

Cα-level descriptors are insensitive to side-chain changes; local descriptors are insensitive by design to tertiary rearrangements outside the window; angle-based features are noisy at high curvature and near the ±π branch cut; the multimodality screen ranks windows and is not a pocket detector.
