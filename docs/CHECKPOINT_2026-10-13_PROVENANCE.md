# Checkpoint 2026-10-13: Publication Package and Provenance

This dated addendum documents what the `scientific-rebuild` checkpoint of 2026-10-13 publishes, what it deliberately
leaves out of Git, and how the excluded material can be retrieved or regenerated. It changes no frozen protocol,
measurement, outcome or protected artifact.

**Machine-readable companion:** [`benchmarks/audit/checkpoint_2026-10-13_manifest.json`](../benchmarks/audit/checkpoint_2026-10-13_manifest.json),
produced by [`benchmarks/audit/checkpoint_manifest.py`](../benchmarks/audit/checkpoint_manifest.py).
- Each excluded file is listed with its size and hash, checked against the hash recorded by the step that produced
  or downloaded it.
- At packaging time every recorded hash matched and no listed local file was missing.

  - The original is 131 MB, above the GitHub 100 MB per-file limit. The copy uses `xz -9`, single-threaded, and is

  [`benchmarks/audit/ENVIRONMENT_audit_venv_pip_freeze.txt`](../benchmarks/audit/ENVIRONMENT_audit_venv_pip_freeze.txt).

## 3. Disclosures

- **Local paths.** Sixteen frozen results and log files contain absolute local paths (`/home/…`). They are protected
  artifacts and were not edited. No credentials or e-mail addresses were found in the published files.
- **"Read-only" wording.** Several workflows were described as read-only although they **write** a JSON record. They
  inspect existing files without changing them:
  - `eb1/eb1a2_preflight.py`
  - `b2opt/b2opt_workloads.py`
  - `bq2/bq2_workloads.py`
  - `bq3/bq3_memory_preflight.py`
  - `checkpoint_manifest.py`

  Where frozen files say "read-only", read it as "no input data changed and no timing performed; one record file
  written".
- **BQ-2 §3 erratum.** BQ-1's preparation model omitted a per-window term. BQ-1's grid would have made that term
  identifiable; the BQ-2 statement that it "could not be separated" is inaccurate. This is recorded in
  [`B2_DIRECT_P2_QUALIFICATION_PREFLIGHT.md`](B2_DIRECT_P2_QUALIFICATION_PREFLIGHT.md). No verdict changes.
- **Hash records superseded by later, documented edits.** Two recorded hashes no longer match the current files.
  Both are expected, and neither is a frozen protocol or measurement.
  - `adk_feasibility/AMENDMENTS.md`: the Amendment 1 freeze hashed the file before Amendment 2 was appended. The
    Amendment 2 freeze matches the current file.
  - `docs/ONCOLOGY_VALIDATION_REQUIREMENTS.md`: `wpd_heldout_closeout_record.json` hashed the outline as first
    written. The outline was then revised on 2026-10-12 at the user's request; the revision is marked inside the
    document. The earlier text was never committed, so only its hash survives.
- **Already-committed history.** The outgoing history includes earlier local commits from 2026-10-03/04, among them
  `394ce0c` (M2 circular statistics in `topofold-core`). They are published as committed; this checkpoint adds no
  production-code change.
